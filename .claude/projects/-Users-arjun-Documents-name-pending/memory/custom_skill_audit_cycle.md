Project has a documented skill audit cycle in CLAUDE.md organized in 4 phases:

1. **Phase 1 (Design & UX)**: ui-ux-pro-max, frontend-design, emil-design-eng, apple-design, animation-vocabulary — before design work starts
2. **Phase 2 (React Implementation)**: vercel-react-best-practices, vercel-composition-patterns — when building components
3. **Phase 3 (Animation & Transitions)**: vercel-react-view-transitions, improve-animations — when adding motion/interactions
4. **Phase 4 (Performance & Shipping)**: vercel-optimize, web-design-guidelines, writing-guidelines — before merging/deploying

**Why:** Ensure custom skills (ui-ux-pro-max, animation-vocabulary, apple-design) and Vercel audit tools are consistently applied to new work, not skipped.

**How to apply:** Before starting a new page/feature, mention which phase(s) apply and ask me to route through the relevant skills. Example: "Run this through Phase 2 & 3 before we ship."

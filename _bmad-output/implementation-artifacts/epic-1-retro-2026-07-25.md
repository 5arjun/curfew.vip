## What Went Well (keep doing)

1. **Sequencing thesis held.** Spike-before-pipeline (1.2), freeze-contract-last (1.10). Freezing the `shared/` contract only after parsing reality was known *immediately caught two latent bugs* in the draft payload (`set.visibility` and a top-level `segments[]` array — both content/overlay disjointness violations). Those would have become contract debt rippling into E2–E5.
2. **Real-data discipline.** Deferred items are backed by evidence, not speculation — 474 real `.session` files, 23,254 `history_entry` rows, a 930-track catalogue — each with a re-check trigger. The ledger is a de-risked map, not a backlog.
3. **AD-11 applied consistently** ("don't guess, log it with a trigger"): `sane_bpm` upper bound, Unicode path-encoding, duplicate-path tiebreak all left as honest unknowns rather than fabricated fixes.
4. **Adversarial 3-layer code review earned its cost every story** — real patches (panic guards, corrected doc-comment lies, missing boundary tests), not cosmetic noise.

## Challenges (systemic, no blame)

1. **The song-list "stitching" seam.** `stats::EnrichedPlay` never carried `in_library`, but the frozen `SyncPlay.in_library` requires it — and the two lists (plays vs. metadata) are matched by position with no verification. Both risks converge on one unwritten function: the payload glue in Story 2.8. **Top weight** — it's the code that turns played sets into synced data.
2. **`in_library = true` hardcode for Serato 4+.** Honest spine deviation. Candidate real signal (`asset_id > 0`) resolved for only ~4.6% of one DJ's plays. **Resolved this session** — see below.
3. **"Gate green" drift.** Story 1.6 was implemented on a toolchain-less Windows box; "gate green" there meant hand-review with the real gate deferred to CI. It reproduced green (only a `fmt` reflow needed), so no harm landed — but the phrase drifted from its meaning. **Resolved this session** — see below.

## Decisions Made This Session

### D1 — In-library badge: keep "assume in-library"; reject the `asset_id` signal (resolves ai-5)
**Arjun's ground truth (2026-07-25):** "Most, if not all, songs I play are definitely in my library."

This resolves the 4.6% fork decisively: if nearly all played tracks are in-library but `asset_id > 0` only lights up for 4.6%, the signal is **undercounting massively** (likely populated lazily after an "analyze" pass, not at play time). Therefore:
- **Keep the current "assume in-library" for Serato 4+** — it matches reality; the alternative signal is proven wrong by ground truth.
- **Do NOT adopt `asset_id`** as the `in_library` source. Switching would falsely mark library tracks as off-library.
- **Lower stakes than feared:** Arjun's primary install is the *legacy* format, where `in_library` is computed properly (not assumed). The assume-true shortcut only affects DJs on the newest Serato, where "most play their own library" makes it usually-right. The badge's real job — flagging the rare off-library track — still works on the legacy path.
- **Residual (narrowed):** confirm generality with a *second real DJ profile* in Epic 2+ — the question is now "does any DJ play heavily off-library?", not "should we adopt the broken signal?" **Epic 3 can safely render the badge.**

### D2 — Local gate is a hard precondition (resolves ai-8)
**Decision:** "Gate green" must mean the four-command gate was **actually run on the machine before calling the work green** — no more "looks right, CI will confirm." A hard precondition, not a suggestion.

### D3 — Decisions A & B propagation: attach-to-trigger (resolves ai-6/ai-7 timing)
Don't rewrite PRD/Architecture/UX now. The decisions doc stays the source of truth; each decision fires when its epic's stories are created:
- **Decision A (go-forward-only / sparse-first dashboard)** → applied at **Epic 3 story-creation**.
- **Decision B (history-as-asset copy; re-spec 4.4/4.5)** → applied at **Epic 4 story-creation**.
Nothing is lost because it's tied to the exact stories that need it.

### D4 — Story 1.8 confidence thresholds stay frozen (confirms ai-4)
Cosmetic number, correct shape, reversible at read time. Tuning on one DJ is theater; real recalibration waits for Epic 4 + fleet data. 865-play rapid-preview blind spot gets one sentence in Story 4.1.

## Key Takeaways

1. **Freeze last, and the freeze pays you back** — the contract freeze caught two latent disjointness bugs precisely because it came after parsing reality was known.
2. **One DJ's ground truth can resolve a data mystery a whole analysis couldn't** — "my songs are all in my library" killed the 4.6% signal question in one sentence.
3. **Deferral with a trigger is not deferral** — the discipline that made Epic 1's large ledger safe to carry into Epic 2.
4. **Epic 2 cashes Epic 1's checks** — its readiness is about not forgetting three pinned items, above all the Story 2.8 stitching.

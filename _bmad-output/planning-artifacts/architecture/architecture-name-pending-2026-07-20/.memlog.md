- (decision) [ADOPTED] Paradigm = local-first hybrid, 'smart edge / thin cloud' (research Topology B). Binds whole system. Prevents a cloud-centric or fully-local variant that can't reach the social endgame without a rewrite. Rule: all parse/join/normalize/stat compute runs on the agent (edge); cloud is store-and-serve + social graph.
- (decision) [ADOPTED] Raw-data boundary: raw Serato .session files and raw library DB NEVER leave the machine (FR-3); only a derived, normalized JSON doc per set crosses. Prevents cloud parsing Serato binary; format-coupling + privacy liability in cloud.
- (decision) [ADOPTED] Two stores, tightened ownership: cloud Postgres is cross-device system of record for synced+social data; local SQLite is a durable parse+offline cache, source of truth for a set ONLY until it syncs. Prevents two-owner divergence across a DJ's multiple machines (tightens research's loose wording).
- (decision) [ASSUMPTION] set_id is DETERMINISTIC from stable session identity (not random-per-parse), so re-parse/backfill re-syncs (idempotent update), not a duplicate. Prevents duplicate sets on backfill — the exact case local raw-retention requires. Research left key-derivation unspecified.
- (decision) [ADOPTED] Sync = idempotent PUT /sets/{set_id} over HTTPS+JWT; offline sets queue durably in local SQLite, sync on reconnect (at-least-once + idempotent = no dupes). Agent owns queue + set_id. Prevents dropped/duplicated sets on flaky venue wifi.
- (decision) [ADOPTED] Per-DJ isolation at DB layer via RLS 'auth.uid() IS NOT NULL AND auth.uid() = dj_id' (null-safe), NOT app-layer. Prevents cross-DJ leak from any API/app bug. Phase 2 social adds explicit opt-in read policies; isolation-by-default stays.
- (decision) [ASSUMPTION] Set CONTENT flows one-way agent->cloud. User-authored overlays (Layer 2 enrichment, segment edits, per-track hide, visibility) are web-authored, cloud-only, never written back to the agent. Agent emits the immutable as-played set; overlays accrete server-side. Prevents bidirectional sync + edit-conflict complexity.
- (decision) [ADOPTED] All cloud mutations go through Supabase (PostgREST/supabase-js) guarded by RLS; no bespoke mutation API server at v1. Agent's ONLY write is the idempotent set sync. Prevents a custom write-API that bypasses RLS.
- (decision) [ASSUMPTION] Stat-compute boundary has one exception: per-set/per-DJ stats are edge-computed, never recomputed in cloud; cross-DJ SCENE aggregates (FR-24/25, Phase 2) are computed IN-CLOUD via SQL over shared sets. Prevents both 'recompute my own stats server-side' and a doomed edge-side scene aggregation.
- (decision) [ASSUMPTION] Genre normalization: cloud stores BOTH raw genre string AND normalized value + taxonomy_version per play. Agent normalizes before sync (FR-8, Curfew-maintained fixed table), but retaining raw+version lets FR-9 trends be recomputed consistently when the table evolves across the fleet. Prevents silent cross-time trend corruption.
- (decision) [ADOPTED] Sync contract = single versioned schema owned by shared/ package (TS types/JSON-schema), validated on BOTH agent (pre-send) and cloud (on-receive) via contract tests. Binds agent<->cloud seam. Every set carries agent_version. Prevents incompatible payload shapes.
- (decision) [ADOPTED] Visibility/privacy: 3 tiers (public/friends-only/private) enforced by RLS read policies; per-track hide = REDACTED PLACEHOLDER, never omission (FR-22); plays inherit their set's visibility, no independent visibility. Default public on sync (Phase 2); Phase 1 all sets dashboard-only. Prevents hide leaking via track-count/omission; UI-only visibility.
- (decision) [ADOPTED] Auth = Supabase Auth (GoTrue) JWT+refresh; multi-provider (email+pw, Google, Apple, passkey) all linked to ONE dj account by verified email (FR-29); phone required on file; djs row 1:1 auth.users. - (decision) Webhook handler = Next.js Route Handler on Vercel, NOT a Supabase Edge Function. Keeps billing in the same single Next.js deployment AD-14 already establishes (no second runtime/deployment surface for one webhook); App Router route handlers can read the raw body needed for Stripe signature verification (stripe.webhooks.constructEvent). The handler authenticates via the Stripe signature (not a Supabase JWT) and writes with the Supabase SERVICE-ROLE key, scoped only to billing columns on djs. This is THE one sanctioned exception to AD-8 ('all cloud mutation through Supabase + RLS, no bespoke write path') — scoped narrowly to billing events, nothing else. Prevents an ambiguous/duplicated write path for subscription state and a second ops surface to operate.
- (decision) Additive-only columns on djs (AD-15 compliant): stripe_customer_id, stripe_subscription_id, subscription_status, current_period_end (all nullable). subscription_status stores Stripe's own status string VERBATIM (trialing/active/past_due/canceled/unpaid/...) rather than a reinterpreted custom enum — the webhook is a thin passthrough, not a second state machine. No separate trial-end column: while status='trialing', current_period_end IS the trial end (Stripe already tracks it). Existing per-DJ RLS (AD-7) already covers a DJ reading their own row's new columns; no new read policy needed. Prevents drift between Stripe's real subscription state and a locally-reinvented one.
- (decision) [HARD INVARIANT] The access gate restricts the WEB experience only. The agent's local capture (parse -> local SQLite -> sync-queue) and the idempotent set-sync endpoint (PUT /sets/:set_id, AD-4) are NEVER gated by subscription_status -- billing state is invisible to the agent and to the sync contract (AD-3). A lapsed subscriber's agent keeps parsing and queuing every set locally and resumes syncing on reactivation: nothing is lost. Only web routes serving the dashboard/stats check subscription_status. Prevents billing logic leaking into the edge<->cloud seam and prevents an implementer gating sync 'for consistency' with the web gate.
- (decision) Free trial is sourced from Stripe's native Checkout trial_period_days, not a hand-rolled trial tracker -- avoids a second source of trial-state truth.

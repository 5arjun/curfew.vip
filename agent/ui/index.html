Curfew Agent

Point Curfew at the Serato library it should watch.

Curfew reads the play history Serato already keeps — which tracks you played, and when. It never opens, copies or uploads your audio files.

Where is my Serato folder?
  • It is the folder named _Serato_. Choose that folder itself, not the folder it sits in.
  • On a Mac it is usually ~/Music/_Serato_. On Windows, %USERPROFILE%\Music\_Serato_.
  • Play off an external drive? Choose the _Serato_ at the top level of that drive — for example /Volumes/MY SSD/_Serato_.
  • Unplugging that drive is fine. Curfew waits for it and picks up where it left off the next time it is connected — you do not need to come back here.
